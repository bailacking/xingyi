# 手谈联机协议

主机通过本机地址（`http://127.0.0.1:<端口>` 或 `http://localhost:<端口>`）打开完整星弈。同网段棋友扫房间二维码，或打开主机的局域网地址并输入房间码，页面直接进入手谈。开发时主机可用 Vite 的本机地址，二维码指向服务端实际监听端口。启动前先构建前端，让服务端能给手机返回页面。

## 访问范围

- 本机管理请求须来自回环地址，且访问的主机名也是回环地址。配置、引擎、个人对局、进度和主题包均适用。
- 同网段访客可用 `GET /api/lan`、`GET /api/net` 和手谈房间接口。浏览器请求使用同源地址，服务端校验 Host 和 Origin。房间码允许同网段加入与观战。
- 入座和自动回座使用浏览器保存的随机 128 位标识。棋手操作要求对应的座位标识，观战离开只移除观众。房间快照只带昵称。手谈使用局域网 HTTP，设计范围是信任的同网段。
- 主机事件使用本机专用 `/ws`。访客通过 `/ws/rooms?room=房间码` 订阅单个房间。服务端发送当前快照及后续变动，断开时客户端用房间接口轮询。配置、进度、引擎与本机对局消息只进入本机事件流。

## 房间与发现

- `POST /api/room` 建房，`POST /api/room/:code/join` 入座，`GET /api/room/:code` 获取盘面、棋钟与聊天。
- `POST /api/room/:code/settings` 由房主在等待阶段修改让子、时间制；`/action` 接收落子、停一手、认输、悔棋与离开；`/chat` 由已入座或观战者发送聊天。
- UDP 7389 广播等待中房间的摘要及实际 HTTP 端口。端口被占用顺延时，发现结果与二维码使用顺延后的端口。房间、观众数量与请求体积均有上限。
