# 主题规范

主题**不重写界面**，只做两件事：改 Token、挑组件变体。这是一个人维护还能做到"深度个性化"的唯一办法。

---

## 一、主题包结构

```
my-theme/
├─ theme.json        tokens + variants + 元信息
├─ style.css         可选，特殊效果
├─ board/            棋盘图、棋子图（可选）
├─ sound/            落子 / 提子 / 磬（可选）
└─ decor/            装饰层素材（可选）
```

## 二、theme.json

```json
{
  "id": "walnut",
  "name": "胡桃木",
  "author": "xingyi",
  "version": "1.0.0",
  "description": "米白、深胡桃木、细金线。",
  "builtin": true,
  "tokens": {
    "color": {
      "bg": "#F7F4EE",
      "surface": "#FFFDF9",
      "surfaceAlt": "#F1EBE0",
      "primary": "#3E2C20",
      "accent": "#A98C5F",
      "text": "#2A2622",
      "textDim": "#6B625A",
      "line": "#DCD2C2",
      "board": "#E5C08A",
      "boardEdge": "#C79E67",
      "boardLine": "#4A3A2A",
      "blackStone": "#15110E",
      "whiteStone": "#FCFAF5",
      "seal": "#9C3A2E",
      "sealText": "#FBF7F2",
      "danger": "#B4432F",
      "ok": "#4E7A52"
    },
    "radius": { "sm": 2, "md": 4, "lg": 6 },
    "shadow": 0,
    "density": "comfortable",
    "motion": { "speed": 200, "bounce": false },
    "font": { "title": "serif", "body": "system-ui" },
    "decor": [],
    "playerMark": "seal"
  },
  "variants": {
    "button": "flat",
    "panel": "paper",
    "playerMark": "seal",
    "result": "plain"
  }
}
```

### 字段约束

| 字段 | 取值 | 说明 |
|---|---|---|
| `shadow` | 0~3 | 0 = 几乎无阴影（典雅），3 = 柔光（年轻） |
| `density` | `comfortable` / `compact` | 控制面板内边距 |
| `motion.speed` | 毫秒 | 所有过渡的时长 |
| `motion.bounce` | 布尔 | 是否允许弹性 |
| `decor` | `[]` / `["glow","particles"]` | 装饰层；性能不达标会被自动关掉 |
| `playerMark` | `seal` / `avatarCard` | 目前只有 `seal` 实现（角色系统 P7 后再说） |
| `variants.button` | `flat` / `soft` / `glow` | |
| `variants.panel` | `paper` / `glass` / `solid` | `glass` 用毛玻璃，低性能设备会降级 |
| `variants.result` | `plain` / `card` | 结算页形态 |

**不认识的字段一律忽略，不报错。** 这样旧版本程序打开新主题不会直接崩。

## 三、安全限制（硬性）

| 允许 | 禁止 |
|---|---|
| 自定义属性、过渡动画、滤镜、伪元素、背景图 | `@import`、任何远程 URL、JS |

理由：

- 远程 URL 会让"离线可用"变成假话，也是隐私泄露的口子
- JS 在开源软件里等于把执行权限交给随便一个主题包

加载前会校验 `theme.json`；主题目录里的 `.js` 文件一律拒绝加载并提示。

## 四、两套内置主题

| 主题 | 定位 | 关键差异 |
|---|---|---|
| **胡桃木**（默认） | 典雅大气 | 宋体、2~6px 直角、无阴影、无装饰、200ms 淡入、印章 |
| **星弈·青** | 年轻群体 | 墨青夜（深青底 + 金线 + 紫光）、黑体、12~24px 大圆角、柔光、装饰层、320ms 弹性 |

星弈·青不只是"给年轻人用"，更是主题系统的**压力测试**：如果它做不出来，说明 Token 不够深，得回头改架构。

> 当前实现里两套主题都用印章（立绘卡还没做），差异体现在颜色、圆角、阴影、动效、面板变体上。
> 这是有意的：先把 Token 层打通，再考虑 `avatarCard`。

## 五、字体

| 用途 | 字体 | 许可 |
|---|---|---|
| 标题 / 模式名 / 印章 | 思源宋体 Source Han Serif SC | SIL OFL 1.1 |
| 正文 / 数字 / 按钮 | 思源黑体 Source Han Sans SC | SIL OFL 1.1 |

字体**不随仓库分发**，用系统已安装版本；没装会回退到 `Songti SC` / `Microsoft YaHei` 之类。
安装方式：Adobe 官方 release 或系统包管理器；装完刷新页面即可。

## 六、加一个新主题的流程

1. 复制 `web/src/theme/skins.ts` 里的一套 tokens，改颜色与圆角
2. 起 `npm run dev`，在设置页看实时预览卡片
3. 切过去，把主界面、对局页、设置页、结算页各走一遍（发布前 checklist）
4. 导出的 zip 与导入功能在 P6 补
