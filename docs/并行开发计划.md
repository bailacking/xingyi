# 并行开发计划（多窗口分工）

> 目的：把剩余工作拆成**文件边界清晰、互不冲突**的任务卡，一个窗口只做一张卡。
> 这样每个会话的上下文都很短，token 花在代码上，不花在回忆上。
>
> 开工前每个窗口只读三样：`AGENTS.md`（§0 开工检查 / §2 状态 / §16 配方）+ 本文档的**自己那张卡** + 要改的文件。
> 不要通读 `docs/archive/PLAN-v2.5.md`。

- 最近提交：`dd887fc`；`npm test` **102 项全绿**；`npm run typecheck` 全过。
- 可玩：自在（对弈/分析/摆棋/复盘/计时/让子）、修习（定级/升降级/跳档）、手谈（房间/观战/聊天/二维码）、教学（2 课 + 100 题 + 测级）。

## 1. 并行规则（违反就会互相踩）

1. **一窗口一张卡**。卡里没写的模块不许改。
2. **文件所有权**：只改卡片「所有权」列出的文件；新增文件放卡片指定的位置。
3. **公共热点文件**（`server/src/api.ts`、`server/src/gameService.ts`、`web/src/Settings.tsx`、`README.md`）：
   只允许在自己的那一段里加代码（路由块 / 方法块 / 面板块），**不要重排、不要格式化整文件**。
4. **样式**：不要往 `web/src/styles.css` 里加东西。新样式写到 `web/src/styles/<模块>.css`，由组件 `import`。
5. **测试**：新测试写自己的 `server/test/<模块>.test.ts` / `packages/*/test/<模块>.test.ts`，不改别人的断言。
6. **提交**：`feat(<模块>): …` / `fix(<模块>): …`，一次一卡，推送前先 `git pull --rebase`。
7. **收尾固定动作**（每张卡做完都做）：
   `npm test` + `npm run typecheck` 全绿 → commit → push → 把本文档该卡的「状态」改成「完成（commit 号）」→ 工作记忆追加 5 行。
8. **设计决策不自己拍**：遇到「要改数据格式/要加依赖/要动等级表结构」这类，先在卡里写方案 + 两个选项，停下来问大帅。

### W1 · 定式练习

**目标**：教学里新增「定式」tab，能在 19 路角部按标准序列跟做，走错立刻指出来。

**必须做**
1. 数据格式定在 `data/joseki/index.json`（+ 每题一个 `joseki/<id>.json` 可选），字段：
   `id / title / size / category / steps[{color, vertex}] / note`，坐标沿用 `y*size+x`。
2. 先做 6 个最常见的：星位小飞挂·一间跳、星位小飞挂·二间跳、点三三·挡、小目一间高挂·托退（简化到 6 手内）、三三·扳、星位·拆二。**每条序列都要在规则层验证过合法**。
3. 服务端：`GET /api/joseki`（列表）、`GET /api/joseki/:id`（不含答案）、`POST /api/joseki/:id/check {step, vertex}`
   → `{ correct, expected?: string, done }`（`expected` 用 GTP 坐标，供提示）。
4. 前端：LearnView 加「定式」tab：列表 → 棋盘跟做 → 走对自动走下一手 → 走错显示「第 N 手应下 Q16」+「重来」。
5. 测试：`server/test/joseki.test.ts`（每题的每一步在空盘上都合法、check 的对错分支）。

**验收**：`npm test` 绿；6 个定式都能完整跟完；走错有中文提示且不卡死。
