# 手动测试清单（P0/P1 基线）

> 每次改完核心链路跑一遍。勾不上的项就是回归。

## 启动

```bash
npm install
npm run build:packages
npm run dev
```

- [ ] 终端出现两行：`[星弈] 服务已启动：http://127.0.0.1:7388` 与 `VITE ready`
- [ ] 打开 <http://localhost:5173> 能看到主界面（标题「星弈」+ 三个模式）

> 注意：Vite 绑定的是 `localhost`，用 `127.0.0.1:5173` 可能连不上。服务端两个都行。

## 主界面

- [ ] 未配置引擎时「修习」可以查看准备页，确认开局按钮不可用，手谈可用，并有说明（置灰不是隐藏）
- [ ] 「自在」可点
- [ ] 底部提示说明"没有引擎也能用离线对手"

## 自在模式

- [ ] 能落子；AI 在 1 秒内应手；白棋落下时有一声轻响
- [ ] 同一落点重复点击提示「该点已有棋子」
- [ ] 自杀点被拒（例如把子往对方虎口里填），提示是「这是自杀点：落下去自己的棋没有气」
- [ ] **回归**：落子接上自己那块还有外气的棋（刺、接、挖）**必须能下**——不能报自杀
- [ ] 「悔棋」回退两手（你 + AI），AI 会重算
- [ ] 「停一手」有效；双方都停后侧栏出现「数子」面板
- [ ] **离线对手会自己收手**：局面定型后它会停一手（不会一直填到棋盘满）
- [ ] 「终局数子」按钮：随时结束并进入数子（不对的盘面也能先看目数）
- [ ] 数子面板出现时棋盘仍然可见可点（不是全屏遮挡）
- [ ] 数子面板：点棋盘上一颗死子 → **整块**一起标死（出现红叉），黑白目数与结论随之变化；再点取消
- [ ] 「确认结算」后弹出结算卡片，显示胜负
- [ ] 展开「新局设置」，改路数 / 难度后点「开始新对局」生效
- [ ] 「导入棋谱」能读入一个 SGF 文件并还原手数
- [ ] 键盘 F 切换形势图（需要引擎才有数据）
- [ ] 落子虚影：默认是**小方块**；设置里可切回「棋子虚影」，两种在胡桃木与星弈·青下都看得清
- [ ] 场景：19 路、9 路各下一盘，棋盘都不溢出窗口

## 修习模式（需要 KataGo）

- [ ] 设置页填好引擎 → 「保存并自检」四项都绿
- [ ] 进「修习」→ 看到累计战绩和下一局难度，返回无输局，点「确认开局」才进入对战
- [ ] 侧栏显示「定级赛 第 1 盘 · 对手 十三级」
- [ ] 「悔棋」是灰的，鼠标悬停给出原因
- [ ] 形势面板显示"修习模式不显示胜率与点评"
- [ ] 认输 → 结算卡片显示「已计入进度 · ±R」「X级」
- [ ] 最多五盘定级后回到菜单，显示「你的名字 · X级（暂定）」
- [ ] 中途退出会提示"算负"
- [ ] 下一盘换颜色；重复开局回原局；双方停手后由 KataGo 裁定死子

## 音效

- [ ] 设置 → 音色：玉石 / 青瓷 / 木石 三档，点一下当场试听（落子 + 提子各一声）
- [ ] 音量滑杆能调到 0（静音）与 100（明显更响）
- [ ] 提子的声音比普通落子略高、略响（不是同一声音）
- [ ] 悔棋/撤销时**不该响**（只有"盘面多了一子"才响）
- [ ] 终局弹出结算时有一声磬

## 主题

- [ ] 设置 → 主题：两套卡片都有实时预览（不是截图）
- [ ] 点「星弈·青」整站变暗色，底部出现「已切换到…·撤销」
- [ ] 5 秒内点「撤销」能回去
- [ ] 刷新页面仍是切换后的主题

## 评级沙盘

- [ ] 设置 → 关于 → 评级沙盘 → 「连赢 12 盘」：出现 12 个小格，等级逐步上升
- [ ] 「连败 12 盘」：等级下降但不会一路掉到底（保级期/退级缓冲）
- [ ] 跑完沙盘后 `data/progress.json` 没变（沙盘不动存档）

## 存档与容错

- [ ] 设置 → 存档管理：新建、切回旧档、导出 JSON、取消删除、确认删除
- [ ] 最后一档删除后，修习提示新建存档，重启后不会恢复旧档
- [ ] `data/progress.json` 是原默认档，新建档在 `data/saves/<id>/`；分别有备份
- [ ] `data/backups/progress-YYYYMMDD.json` 每天一份
- [ ] 手动把 progress.json 改坏 → 重启服务 → 自动从 `.bak` 恢复
- [ ] 杀掉服务端 → 前端顶部出现断线 → 重启服务后自动重连（2 秒一次）

## 已知限制（不是 bug）

- 修习模式在没装 KataGo 时**不给进**（引擎校准分未实测，硬凑只会让人误解棋力）
- 离线对手不是 KataGo，棋力是"能下不荒唐"，不计入进度
- 两个模型已实测可共用同一进程（双模型显存 985MB / 4096MB，见 docs/引擎安装.md 第六节）
- 摆子编辑（AB/AW/AE）与目差曲线、逐手失误标注都还没做（P1/P2 余项）


## 复盘 / 摆棋 / 手谈（2026-10-18 新增）

- [ ] 下完一盘点「复盘」：出现胜率曲线；点曲线或手数能跳转盘面
- [ ] 终局侧栏显示结算。点「复盘」进入，曲线、滑杆、关键着同步跳转
- [ ] 摆棋：点「摆棋」→ 黑白擦切换 → 落子 → 「开始分析」，胜率/目差随摆的子变化
- [ ] 悔棋后「重做」能恢复；重做栈空了按钮置灰
- [ ] 拖一个 .sgf 到棋盘上能导入
- [ ] 手谈：A 创建房间拿到 6 位码；B 用码加入执白；C 加入变观众
- [ ] 手谈：A 申请悔棋，B 同意后手数减一；聊天双方可见

## 计时 / 让子 / 着法名（2026-10-19 新增）

- [ ] 自在 → 新对局面板选「让 4 子」→ 开始：四角星位出现 4 颗黑子，右上角显示「让 4 子」，白先走，贴 0.5 目
- [ ] 时间选「3 分包干」，故意不走：自己的表归零后判超时负（结果显示「黑/白超时」）
- [ ] 时间选「10 分 + 3×30 秒」：主时间用完后出现「读秒 ●●●」，每手重置
- [ ] 手数面板里能看到着法名（尖/飞/跳/长/立/接/打吃），看不懂的棋不硬标
- [ ] 手谈：局域网地址只能进手谈，本机地址可进设置与修习
- [ ] 手谈：大厅首屏显示加入和创建，房间内展开「邀请棋友」可见二维码，手机扫码直接入座；刷新页面自动回到原座位
- [ ] 手谈：对方落子/聊天**即时**出现（不再等 1.2 秒轮询）

## 界面细节（2026-10-19）

- [ ] 自在模式切换 9/13/19 路：棋盘**立刻**换成新尺寸并重开一局（不用再点「重新开局」），手数归零、计时钟重置
- [ ] 切路数时如果正在摆棋/复盘，会自动退出该状态

## 零基础围棋入门（2026-11-13）

- [ ] 首页点「教学」打开「轮流落子」，先后走两手；重复点已有棋子后才可进下一课。
- [ ] 找气时共用气只算一次，点「显示提示」不推进进度；「重练本课」能回到原局面。
- [ ] 提子练习移除两颗白棋；禁着点先被拦住，再试一手可以提子的落点。
- [ ] 立即提劫被拦住；右上交换后回去能提回。
- [ ] 双方停手后标记死子；取消标记会禁用确认；数子后显示双方活子、空点、贴目和结果。
- [ ] 完成后进入 KataGo 9 路、不限时的 25 级自在局。未装双模型时转到引擎设置，返回后仍停留在结课。

## 第一盘棋的教学复盘

- [ ] 完成 KataGo 分先局后可点「看一手，试一次」，看到扫描和深查进度。
- [ ] 点非法落点时留在原局面并提示原因；点合法落点时显示试下目差和预计应对，推荐点仍可查看。
- [ ] 在同一手数切换「我的试下」「实战变化」「推荐变化」。重练达到目标才记录练对日期。
- [ ] 逐手播放、切换「实战变化」与「推荐变化」，目差以玩家执色为准。返回结算后，正式棋谱和结果一致。
- [ ] 引擎不可用或没有明显可展示的差异时，显示原因并可返回结算。

## 我的错题

- [ ] 从首盘复盘点「加入我的错题」，返回结算后重开复盘显示已收录。
- [ ] 重启服务后，从「教学 → 我的错题」打开原局面，能提示、落子和回放实战。
- [ ] 下错保持「待回练」，下对显示「上次练对」。刷新页面后日期仍在。
- [ ] 「移除」先确认，取消保留；确认后只移除错题。

## KataGo 一键安装（Windows x64）

- [ ] 用空数据目录启动，从「设置 → 引擎」一键下载。中断后重试，已下载文件复用。
- [ ] CUDA 缺运行库时继续试 DirectML；显示就绪前已加载双模型并用 25 级试下一手。
- [ ] 重启后使用自动保存的配置，开 9 路 25 级自在局，确认由 KataGo 应手。
