# 手动测试清单（P0/P1 基线）

> 每次改完核心链路跑一遍。勾不上的项就是回归。

## 启动

```bash
npm install
npm run build:packages
npm run dev
```

- [ ] 终端出现两行：`[星弈] 服务已启动：http://127.0.0.1:7388` 与 `VITE ready`
- [ ] 打开 <http://localhost:5173> 能看到主界面（标题「星弈」+ 三个模式）

> 注意：Vite 绑定的是 `localhost`，用 `127.0.0.1:5173` 可能连不上。服务端两个都行。

## 主界面

- [ ] 未配置引擎时「修习」「手谈」是灰的，并有说明（置灰不是隐藏）
- [ ] 「自在」可点
- [ ] 底部提示说明"没有引擎也能用离线对手"

## 自在模式

- [ ] 能落子；AI 在 1 秒内应手；白棋落下时有一声轻响
- [ ] 同一落点重复点击提示「该点已有棋子」
- [ ] 自杀点被拒（例如把子往对方虎口里填），提示是「这是自杀点：落下去自己的棋没有气」
- [ ] **回归**：落子接上自己那块还有外气的棋（刺、接、挖）**必须能下**——不能报自杀
- [ ] 「悔棋」回退两手（你 + AI），AI 会重算
- [ ] 「停一手」有效；双方都停后侧栏出现「数子」面板
- [ ] **离线对手会自己收手**：局面定型后它会停一手（不会一直填到棋盘满）
- [ ] 「终局数子」按钮：随时结束并进入数子（不对的盘面也能先看目数）
- [ ] 数子面板出现时棋盘仍然可见可点（不是全屏遮挡）
- [ ] 数子面板：点棋盘上一颗死子 → **整块**一起标死（出现红叉），黑白目数与结论随之变化；再点取消
- [ ] 「确认结算」后弹出结算卡片，显示胜负
- [ ] 改路数 / 难度 → 点「重新开局」生效
- [ ] 「导入棋谱」能读入一个 SGF 文件并还原手数
- [ ] 键盘 F 切换形势图（需要引擎才有数据）
- [ ] 落子虚影：默认是**小方块**；设置里可切回「棋子虚影」，两种在胡桃木与星弈·青下都看得清
- [ ] 场景：19 路、9 路各下一盘，棋盘都不溢出窗口

## 修习模式（需要 KataGo）

- [ ] 设置页填好引擎 → 「保存并自检」四项都绿
- [ ] 进「修习」→ 直接开一局（不打难度选择）
- [ ] 侧栏显示「定级赛 第 1 盘 · 对手 八级」
- [ ] 「悔棋」是灰的，鼠标悬停给出原因
- [ ] 形势面板显示"修习模式不显示胜率与点评"
- [ ] 认输 → 结算卡片显示「已计入进度 · ±R」「X级」
- [ ] 三盘定级后回到菜单，显示「你的名字 · X级（暂定）」
- [ ] 中途退出会提示"算负"

## 音效

- [ ] 设置 → 音色：玉石 / 青瓷 / 木石 三档，点一下当场试听（落子 + 提子各一声）
- [ ] 音量滑杆能调到 0（静音）与 100（明显更响）
- [ ] 提子的声音比普通落子略高、略响（不是同一声音）
- [ ] 悔棋/撤销时**不该响**（只有"盘面多了一子"才响）
- [ ] 终局弹出结算时有一声磬

## 主题

- [ ] 设置 → 主题：两套卡片都有实时预览（不是截图）
- [ ] 点「星弈·青」整站变暗色，底部出现「已切换到…·撤销」
- [ ] 5 秒内点「撤销」能回去
- [ ] 刷新页面仍是切换后的主题

## 评级沙盘

- [ ] 设置 → 评级沙盘 → 「连赢 12 盘」：出现 12 个小格，等级逐步上升
- [ ] 「连败 12 盘」：等级下降但不会一路掉到底（保级期/退级缓冲）
- [ ] 跑完沙盘后 `data/progress.json` 没变（沙盘不动存档）

## 存档与容错

- [ ] `data/progress.json` 存在，且同目录有 `.bak`
- [ ] `data/backups/progress-YYYYMMDD.json` 每天一份
- [ ] 手动把 progress.json 改坏 → 重启服务 → 自动从 `.bak` 恢复
- [ ] 杀掉服务端 → 前端顶部出现断线 → 重启服务后自动重连（2 秒一次）

## 已知限制（不是 bug）

- 修习模式在没装 KataGo 时**不给进**（引擎校准分未实测，硬凑只会让人误解棋力）
- 离线对手不是 KataGo，棋力是"能下不荒唐"，不计入进度
- 12 级以上已实测可共用同一进程（双模型显存 985MB / 4096MB，见 docs/引擎安装.md 第六节）
- 摆子编辑（AB/AW/AE）与目差曲线、逐手失误标注都还没做（P1/P2 余项）


## 复盘 / 摆棋 / 手谈 / 题库（2026-10-18 新增）

- [ ] 下完一盘点「复盘」：出现胜率曲线；点曲线或手数能跳转盘面
- [ ] 输棋后自动进复盘（不想看可以点「退出复盘」）
- [ ] 摆棋：点「摆棋」→ 黑白擦切换 → 落子 → 「开始分析」，胜率/目差随摆的子变化
- [ ] 悔棋后「重做」能恢复；重做栈空了按钮置灰
- [ ] 拖一个 .sgf 到棋盘上能导入
- [ ] 手谈：A 创建房间拿到 6 位码；B 用码加入执白；C 加入变观众
- [ ] 手谈：A 申请悔棋，B 同意后手数减一；聊天双方可见
- [ ] 教学 → 题库：点「提一子（中间）」，下在最后一口气上显示「正解：提掉 1 子」
- [ ] 教学 → 10 题测级：做完给出答对数与级别建议
